# Effect spec: `RoundCorners`

Rounds the corners of the layer: the "Corner Rounding" effect.

Tags: **[obs]** observed in files, **[inf]** inferred, **[?]** unknown.
For the shared evidence see `README.md`.

## Parameters

[obs, E-demo: on camera `VMFile` 8 and mirrored on its `UnifiedMedia`
parent 7]:

| Name | Type | Demo value | Meaning / units |
|---|---|---|---|
| `radius` | animatable double | 233.809757619281 | Corner radius in **layer px**, before scale [inf, strong: 233.809757619281 × scale 0.28869624898167 = 67.5000000000 canvas px exactly] |
| `top-left` | animatable double | 1.0 | Enables or weights this corner [inf]: 1 = rounded, 0 = square |
| `top-right` | animatable double | 1.0 | As above |
| `bottom-left` | animatable double | 1.0 | As above |
| `bottom-right` | animatable double | 1.0 | As above |

- The corner flags are doubles, not bools, and they are animatable [obs]. A
  fractional value probably scales that corner's radius [inf, weak].
- `top`/`bottom` refer to the screen (y-down) sense [inf].
- **Default radius.** In the UI the user sets it in canvas px, and the stored
  value is that number divided by the clip scale [inf]. A fresh default is
  [?]; EF0 gives it.

## Model

```
r_c   = radius · flag_c                       (layer px)
r_c   = min(r_c, w/2, h/2)                    clamp to half the shorter side [inf]
alpha = alpha · insideRoundedRect(w, h, r_tl, r_tr, r_bl, r_br)
```

- The rectangle is the layer's natural rectangle after `sourceCrop` [inf].
- Edges are anti-aliased over about 1 output pixel [inf].

### Demo check

- The camera's circle comes from `Mask` (an ellipse), not from these
  corners: 67.5 canvas px is far below the circle's 155.9 px radius
  (`Mask.md`) [obs].
- `RoundCorners` sits **before** `Mask` in `effects[]`. Applied first, it
  rounds the 1920×1080 frame's corners, which the 1080×1080 central mask then
  cuts away entirely. That agrees with the picture [obs: the circle is round
  at every angle, radius 52.0 ± 0.4 thumbnail px measured every 15°].
