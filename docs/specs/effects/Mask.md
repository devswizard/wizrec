# Effect spec: `Mask`

Keeps the part of the layer inside a shape (an ellipse or rectangle), with
optional feather, rotation and inversion. The area outside can stay partly
visible.

Tags: **[obs]** observed in files, **[inf]** inferred, **[?]** unknown.
For the shared evidence see `README.md`.

## Parameters

[obs, E-demo: camera `VMFile` 8, 1920×1080 layer at scale 0.28869624898167]:

| Name | Type | Demo value | Meaning / units |
|---|---|---|---|
| `mask-shape` | constant int | 0 | Shape enum. **0 = ellipse** [inf, strong, below]. Other values [?]: rectangle and rounded rectangle are expected |
| `mask-width` | animatable double | 1080.0 | Shape width in **layer px** [obs, `transform.md` §10] |
| `mask-height` | animatable double | 1080.0 | Shape height in layer px [obs] |
| `mask-positionX` | animatable double | 0.0 | Shape centre, offset from the layer centre in layer px; +y direction [?] (+up, as for translation, is assumed) |
| `mask-positionY` | animatable double | 0.0 | As above |
| `mask-rotation` | animatable double | 0.0 | Shape rotation in radians [inf, as for `rotation2`] |
| `mask-cornerRadius` | animatable double | 0.0 | Corner radius for rectangular shapes, layer px [inf] |
| `mask-blend` | animatable double | −0.02 | Edge feather. Sign and units [?]; the value is small and negative |
| `mask-opacity` | animatable double | 0.0 | Opacity of the area **outside** the shape: 0 = fully hidden [inf: the demo shows no camera pixels outside the circle] |
| `mask-invert` | constant int | 0 | 1 = keep the outside and hide the inside [inf] |

## Observed behaviour (E-thumb)

- The camera appears as a **circle of radius 52.0 ± 0.4 thumbnail px** about
  the camera centre, measured along 24 rays at 15° steps [obs]. A 1080 × scale
  = 311.8 canvas px circle = 103.9 thumbnail px diameter is predicted, and
  that is what we see.
- **Why shape 0 = ellipse.** A 1080×1080 square mask would give a square; its
  diagonal edge would sit at 73.5 thumbnail px, not 52. The only other
  rounding on the clip is `RoundCorners`, whose radius is 67.5 canvas px
  (`RoundCorners.md`); that is too small to turn a 311.8-px square into a
  circle. So the shape itself is an ellipse [inf, strong].
- `mask-blend` −0.02: the circle's edge jumps sharply, with the largest
  colour change within about one thumbnail pixel [obs]. So −0.02 is a hard
  or nearly hard edge. Whether negative values feather inward is [?].

## Model

```
p     = layer pixel relative to (positionX, positionY), rotated by −rotation
inside(p) by shape: ellipse  (p.x/(w/2))² + (p.y/(h/2))² ≤ 1
                    rect     |p.x| ≤ w/2 ∧ |p.y| ≤ h/2, corners rounded by cornerRadius
m     = smooth step across the edge over the feather width (blend)   [?]
m     = invert ? 1 − m : m
alpha = alpha · (m + (1 − m) · mask-opacity)
```

Does the mask also shrink the layer's bounds for the effects after it (for
example a later shadow)? [?] EF3 cell 6 tests it.
