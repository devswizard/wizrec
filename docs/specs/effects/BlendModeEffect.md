# Effect spec: `BlendModeEffect`

Composites the layer onto the layers below it with a blend mode (multiply,
screen and so on) instead of normal source-over.

Tags: **[obs]** observed in files, **[inf]** inferred, **[?]** unknown.
For the shared evidence see `README.md`.

## Evidence

**BlendModePreview** (bundle sample, format 6.0, 240×128, `editRate` 30).
Track 0 holds an image. Tracks 1–3 hold three solid ellipse callouts: red,
green and blue. Tracks 4–6 hold copies of the same three ellipses, at the
same keyframed positions, each carrying `BlendModeEffect` [obs]. Over time
the plain circles fade out (opacity keyframes) while the blended copies'
`intensity` ramps 0 → 1. The preview therefore cross-fades from normal to
blended overlapping RGB discs [inf]. Clip metadata says
`default-BlendModeEffect-mode: "12"` and
`default-BlendModeEffect-intensity: "1"` [obs].

## Parameters

|---|---|---|---|
| `mode` | constant int | 12 | Blend-mode enum, table below. 12 = *Screen* [obs] |
| `intensity` | animatable double | keyframed 0 → 1 → 0 | Mix between normal compositing (0) and the blended result (1) [inf] |
| `invert` | constant int | 0 | [?] Inverts the layer before blending, or inverts the range |
| `channel`, `shadowRampStart/End`, `highlightRampStart/End` | constant | 0; 0, 0; 1, 1 | The shared range block (`ColorAdjustment.md`) |

- `leftEdgeMods`/`rightEdgeMods` fade `intensity` at the clip edges with
  `duration` 0 (`README.md` §1) [obs].
- `intensity` has `defaultValue` 0.0 in the file but keyframes up to 1.0 [obs].
  The metadata default for a newly added effect is 1 [obs].

## Model

```
B = composite of everything below this layer (same parent canvas)
L = this layer after its earlier effects (straight colour, alpha a)
blended = blendFn_mode(B, L)                     per channel, 0–1 sRGB-encoded [inf]
C = mix(L, blended, i)                           where i = intensity
out = B·(1 − a) + C·a                            source-over with the layer's alpha a  [inf]
```

At i = 0 this is plain normal compositing, and at i = 1 the full blend. The
layer never disappears. This matches BlendModePreview, which ramps
`intensity` 0 → 1 while the plain copies fade out. (Corrected 2026-10-19:
the first version of this formula scaled the alpha by `i`, which hid the
layer at i = 0. Wait for EF5 before treating this as settled.)

## EF5: blend sheet (generated by qa)

- **Base:** track 0 carries M-grad, the black→white ramp, across the full
  canvas.
- **Cells:** above it, 24 small cells in a 6×4 grid. Each holds a 200×200
  M-card crop (or a solid 50 % red square) with `BlendModeEffect` set to
  `intensity` 1 and `mode` = cell index 0…23.
- **Out-of-range modes:** for modes past the end of the list, Camtasia will
  probably clamp or ignore them. Either outcome is still informative.

Each cell's colour against the underlying ramp gives that mode's curve. A
second save of this project after the user opens it lets Camtasia normalise
any invalid modes, which shows the valid range.
