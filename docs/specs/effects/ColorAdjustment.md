# Effect spec: `ColorAdjustment`

Brightness, contrast and saturation adjustment of the layer's pixels.

Tags: **[obs]** observed in files, **[inf]** inferred, **[?]** unknown.
For the shared evidence see `README.md`.

## Parameters

[obs, E-vlog: one instance, on `VMFile` 179 and mirrored on its
`UnifiedMedia` parent 178, Camtasia 2026]:

| Name | Type | Vlog value | Meaning | Range |
|---|---|---|---|---|
| `brightness` | animatable double | 0.639999985694885 (float32 0.64) | Brightness change | [?] |
| `contrast` | animatable double | 3.98 | Contrast change | [?] |
| `saturation` | animatable double | 0.0 | Saturation change. 0 = unchanged [inf, weak: the user's colour footage is unlikely to have been made greyscale] | [?] |
| `channel` | constant int | 0 | Shared "range" block (§ below) | enum [?] |
| `shadowRampStart` | animatable double | 0.0 | Range block | 0–1 [inf] |
| `shadowRampEnd` | animatable double | 0.0 | Range block | 0–1 |
| `highlightRampStart` | animatable double | 1.0 | Range block | 0–1 |
| `highlightRampEnd` | animatable double | 1.0 | Range block | 0–1 |

- **Defaults** [inf]: brightness 0, contrast 0, saturation 0, which are
  identity values on an offset scale. EF0 confirms them.
- The odd values 0.64 and 3.98 suggest a UI that shows −100…100 and stores
  the value divided by 100. That would make contrast 3.98 out of range, so
  the scales probably differ per parameter [?]. EF4 settles it.

### The shared "range" block

`channel`, `shadowRampStart/End` and `highlightRampStart/End` also appear,
with identical defaults, on `BlendModeEffect` and `CursorColor` [obs]. They
look like a common tonal-range selector [inf]:

- the effect applies fully to pixels whose luminance (or the chosen
  `channel`) lies between the shadow ramp and the highlight ramp;
- it fades in over [shadowRampStart, shadowRampEnd] and fades out over
  [highlightRampStart, highlightRampEnd];
- with the defaults (0, 0, 1, 1) it applies to every pixel.

Implement the defaults as "the whole image". Non-default behaviour is [?].

## Model (provisional)

The effect works in sRGB-encoded space, consistent with the shader
backgrounds [inf]:

```
y = luma(rgb)
rgb = rgb + brightness·k_b                          offset
rgb = (rgb − 0.5)·f(contrast) + 0.5                 pivot at mid-grey
rgb = y + (rgb − y)·(1 + saturation·k_s)
```

`k_b`, `f` and `k_s` are [?] until EF4.
