# Keyboard shortcuts

⌘ Command · ⇧ Shift · ⌥ Option · ⌃ Control. Single-key shortcuts work while the editor
window is active and no text field has focus.

## Files

| Action | Shortcut |
|---|---|
| New Project | ⌘N |
| Open… | ⌘O |
| Save | ⌘S |
| Save As… | ⇧⌘S |
| Close | ⌘W |
| New Recording… | ⌘R |
| Import Media… | ⌘I |
| Quit WizRec | ⌘Q |

## Editing

| Action | Shortcut |
|---|---|
| Undo / Redo | ⌘Z / ⇧⌘Z |
| Cut / Copy / Paste | ⌘X / ⌘C / ⌘V |
| Select all clips | ⌘A |
| Deselect all | ⇧⌘A |
| Delete selection | ⌫ or ⌦ |
| Ripple delete (close the gap) | ⇧⌫ or ⌘⌫ |
| Split at playhead | S |
| Add marker at playhead | M |
| Group / Ungroup | ⌘G / ⇧⌘G |
| Leave the open group, or clear the selection | Esc |

## Timeline mouse gestures

| Action | Gesture |
|---|---|
| Move clip | Drag (snaps to clip edges, playhead and markers when Snapping is on) |
| Trim | Drag a clip edge |
| Ripple move / ripple trim | ⌥-drag |
| Open a group for editing | Double-click it |
| Add an effect or transition | Drag it from the library onto a clip or a cut |

## Playback and navigation

| Action | Shortcut |
|---|---|
| Play / Pause | Space |
| Previous / Next frame | ← / → |
| Back / Forward 1 second | ⇧← / ⇧→ |
| Go to start | Home or ⌘← |
| Go to end | End or ⌘→ |
| Timeline zoom in / out | ⌘= / ⌘- |
| Zoom to fit | ⌘0 |

## View

| Action | Shortcut |
|---|---|
| Performance overlay | ⌥⌘P |
| Full screen | ⌃⌘F |
| Minimize | ⌘M |
| Hide WizRec / Hide others | ⌘H / ⌥⌘H |

## Recording (global, work in any app while the recorder is open)

| Action | Shortcut |
|---|---|
| Start / Stop recording (also cancels the countdown) | ⇧⌘2 |
| Pause / Resume | ⇧⌘P |
| Cancel region selection | Esc |
