# Library

WizRec's built-in library is original work by Devs Wizard (GPL-3.0-or-later), plus four
open-licence font families. None of it comes from Camtasia. When a project made in Camtasia
uses Camtasia's own backgrounds or effects, WizRec draws them from the copy inside that
project and never copies them anywhere else.

> ⏳ The library panel offers transitions and effects today. Backgrounds, callout presets,
> cursors and click effects are in the library and are drawn by the renderer; their panel
> tabs arrive in an upcoming version.

## Transitions

Drag one onto the cut between two clips, or onto the start or end of a clip (the missing
side is transparent, so lower tracks show through). Default length: 1 second (cube 1.5 s).

| Group | Transitions |
|---|---|
| Fades | Fade, Dissolve, Fade Through Black, Pixel Dissolve |
| Wipes | Soft Wipe, Clock Wipe, Wheel, Barn Door, Blinds, Checkerboard |
| Shapes | Iris, Circle Reveal, Inset |
| Slides | Slide Left, Slide Right, Stretch |
| 3D | Cube, Flip |

They are saved under the format's standard transition names (`Fade`, `SlideLeft`,
`CubeRotate`, …), so Camtasia shows its own version of the same transition when it opens
the project.

## Effects

Rounded Corners, Drop Shadow, Mask, Color Adjustment, Motion Blur. Drag one onto a clip and
adjust it in Properties.

## Backgrounds

Animated, resolution-independent backgrounds: Gradient Drift, Soft Waves, Aurora, Bokeh,
Grid Horizon, Moving Stripes, Radial Pulse, Liquid, Spotlight Glow. Each has colours and a
Speed setting (0 freezes it). A background is stored in the project as a small shader file,
like any other media.

## Callouts

| Group | Presets |
|---|---|
| Shapes | Outline Box, Filled Box, Outline Circle, Star, Triangle, Stop |
| Bubbles | Speech Bubble, Thought Bubble |
| Arrows | Arrow, Double Arrow, Dotted Line |
| Text | Title, Label, Handwritten Note, Lower Third |
| Regions | Blur, Pixelate, Highlight, Spotlight (they act on what is underneath) |

## Cursors and click effects

Cursor images (Arrow, Arrow Light, Pointing Hand, I-Beam, Crosshair) can replace the
recorded cursor; click effects (Ring, Ripple, Burst, Dot) mark clicks.

## Fonts

Montserrat, Lato, Bebas Neue and Caveat are built in (SIL Open Font License 1.1) and
available to callouts and captions without installing them.
